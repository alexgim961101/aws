# 08. Data & Batch — 데이터 파이프라인과 배치

## 목표

S3 기반 데이터 레이크의 기본기를 익히고, 서버 없이 데이터를 적재·카탈로그화·조회하는 미니 파이프라인을 만든다.

## 이론

- [ ] S3 데이터 레이크 개념: 원본/가공 계층 분리, 파티셔닝 전략(날짜 기준 등)
- [ ] 파일 포맷: CSV/JSON vs Parquet — 컬럼 지향 포맷이 스캔 비용을 줄이는 원리
- [ ] Glue: 크롤러, 데이터 카탈로그, ETL 잡(개요 수준), Glue vs 직접 Lambda ETL 선택 기준
- [ ] Athena: 스캔량 과금 모델, 파티션 프루닝, CTAS
- [ ] Kinesis Data Streams / Firehose 개요: 스트리밍 수집이 필요한 순간
- [ ] 배치 설계: EventBridge 스케줄 + Lambda/ECS 태스크, AWS Batch는 언제 필요한가
- [ ] 배치 운영 원칙: 재실행 가능(멱등) 설계, 실패 알림, 백필

## 실습 (labs/)

- 샘플 로그(JSON)를 날짜 파티션 구조로 S3에 적재
- Glue 크롤러로 카탈로그 생성 → Athena로 쿼리
- Athena CTAS로 Parquet 변환 후 스캔량 비교
- EventBridge 스케줄 + Lambda로 일 배치(적재 자동화) 구성

⚠️ 비용: Athena는 스캔량 과금(소량 데이터면 미미), Glue 크롤러는 실행 시간 과금. Kinesis는 상시 과금이므로 실습 제외.
