# 04. Containers — 컨테이너 운영

## 목표

컨테이너 이미지를 ECR에 올리고 ECS Fargate로 배포하며, 무중단 배포를 경험한다.

## 이론

- [ ] Docker 복습: 이미지 빌드, 태깅, 멀티 스테이지 빌드
- [ ] ECR: 리포지토리, 이미지 푸시/풀 권한, 수명주기 정책(오래된 이미지 정리)
- [ ] ECS 핵심 개념: 클러스터 · 태스크 정의 · 태스크 · 서비스의 관계
- [ ] Fargate vs EC2 시작 유형: 운영 부담과 비용의 트레이드오프
- [ ] 태스크 정의 상세: CPU/메모리, 태스크 역할 vs 태스크 실행 역할, 로그 설정(awslogs)
- [ ] ALB 연동: 대상 그룹(ip 타입), 동적 포트 매핑
- [ ] 서비스 오토스케일링과 배포 전략: 롤링 업데이트, blue/green(CodeDeploy) 개요
- [ ] ECS vs EKS 선택 기준: 어떤 조직·워크로드에서 EKS가 정당화되는가 (EKS는 개요 수준)

## 실습 (labs/)

- 간단한 웹 앱 컨테이너 이미지 빌드 → ECR 푸시
- ECS Fargate 서비스 + ALB 구성 (01 VPC 재사용)
- 이미지 새 버전 배포 → 롤링 업데이트로 무중단 배포 관찰
- 태스크 수를 2로 늘려 부하 분산 확인

⚠️ 비용: Fargate는 vCPU·메모리 시간당 과금. 최소 사양(0.25 vCPU)으로 실습 후 destroy.

## 완료 기준
