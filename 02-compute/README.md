# 02. Compute — EC2 기반 웹서비스

## 목표

01의 VPC 위에 로드밸런서·오토스케일링·HTTPS를 갖춘 전형적인 웹서비스 구성을 완성한다.

## 이론

- [ ] EC2 핵심: 인스턴스 타입 패밀리 읽는 법, AMI, EBS 볼륨 타입, user data
- [ ] 인스턴스 프로파일: EC2에 IAM 역할을 부여하는 방법 (00에서 배운 "키 대신 역할"의 실전)
- [ ] ALB vs NLB: L7 vs L4, 각각의 사용처
- [ ] 대상 그룹과 헬스체크: 헬스체크 설정이 배포·장애 감지에 미치는 영향
- [ ] Auto Scaling Group: 시작 템플릿, 원하는/최소/최대 용량, 스케일링 정책(대상 추적 중심)
- [ ] Route 53: 레코드 타입(A, CNAME, Alias), 라우팅 정책 개요
- [ ] ACM: 인증서 발급·검증, ALB에 HTTPS 적용
- [ ] CloudFront 기초: CDN 동작 원리, ALB 앞에 두는 이유

## 실습 (labs/)

- 01의 VPC 모듈 재사용
- 시작 템플릿(user data로 웹서버 설치) + ASG(프라이빗 서브넷) + ALB(퍼블릭 서브넷) 구성
- ACM 인증서 발급 → ALB HTTPS 리스너 적용 (도메인 보유 시 Route 53 연결, 없으면 이론으로 대체)
- 인스턴스 하나를 강제 종료하고 ASG가 복구하는지 관찰

⚠️ 비용: ALB 시간당 과금, NAT GW 포함 시 실습 후 destroy 필수.

## 완료 기준

- notes/ 에 이론 정리 작성
- ALB 도메인으로 접속 성공, 인스턴스 강제 종료 → 자동 복구 확인
- apply → destroy 완주
