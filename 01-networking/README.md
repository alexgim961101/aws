# 01. Networking — VPC 제대로 설계하기

## 목표

이후 모든 단계의 기반이 되는 프로덕션급 2-AZ VPC를 직접 설계하고 Terraform 모듈로 만든다.

## 이론

- [ ] VPC와 CIDR 설계: 사이더 블록 크기 선택, 서브넷 분할 전략, 다른 네트워크(사내망·다른 VPC)와 겹치지 않게 설계하는 이유
- [ ] 퍼블릭 서브넷 vs 프라이빗 서브넷: 무엇이 서브넷을 "퍼블릭"으로 만드는가
- [ ] 라우팅 테이블, 인터넷 게이트웨이(IGW), NAT Gateway: 트래픽이 나가고 들어오는 경로 추적
- [ ] 보안 그룹 vs NACL: stateful vs stateless, 각각 언제 쓰는가
- [ ] VPC 엔드포인트: Gateway(S3, DynamoDB) vs Interface(PrivateLink), 비용·보안 관점의 효용
- [ ] ENI, EIP: EC2 네트워킹의 실체

## 실습 (labs/)

- 2-AZ VPC를 Terraform 모듈로 구축:
  - 퍼블릭 서브넷 ×2, 프라이빗 서브넷 ×2
  - IGW, NAT GW, 라우팅 테이블 연결
  - S3 Gateway 엔드포인트 추가
- 퍼블릭 서브넷에 임시 EC2를 띄워 프라이빗 서브넷 인스턴스로 SSH(또는 SSM) 접속, 아웃바운드 경로 확인

⚠️ 비용: NAT Gateway는 시간당 + 처리량 과금. 실습 후 반드시 destroy.
