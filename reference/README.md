# Reference — 서비스별 딥다이브

phase 본문의 운영 흐름을 유지하기 위해, 특정 서비스를 깊이 파야 할 때는 여기에 서비스 단위 노트로 누적한다.

## 작성 규칙

- 파일명: 서비스 이름 소문자 (예: `s3.md`, `iam.md`, `rds.md`)
- phase 노트에서 "더 깊이"가 필요해진 시점에 만든다 — 미리 만들어두지 않는다
- phase 노트에서 이 문서로 링크를 걸어 연결한다

## 노트 템플릿

```markdown
# <서비스 이름>

## 한 줄 정의
## 핵심 개념
## 운영에서 자주 마주치는 것 (실수, 한계, 요금 함정)
## 관련 phase
```

## 딥다이브 후보 (학습 중 발견 시 추가)

- [ ] (예시) S3 스토리지 클래스 전체 비교와 수명주기 설계
- [ ] (예시) IAM 정책 문법 레퍼런스
